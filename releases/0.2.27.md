# RADAZ 0.2.27

- Ölçmə zamanı görüntünün üzərindəki təlimat yazıları çıxarıldı.
- Ayaq tağı üçbucağını içindən və xətlərindən tutub bütöv daşımaq, üç küncünü ayrıca dəyişmək mümkündür. **H** yazısı ayrıca sürüklənir; ölçü dəyişmədən yazının mövqeyi dəyişir.
- Ellips ROI-ni içindən tutub daşımaq mümkündür. Ölçüsünü tutacaqlardan dəyişmək, görüntü fırladıldıqdan sonra da sürükləmək olur.
- **Yardım → AI ayarları** və AI asistentdəki ayarlar düyməsi: OpenAI API açarını daxil edin, **Yadda saxla**, sonra **Bağlantını yoxla**. Açar Windows hesabına bağlı şifrəli şəkildə saxlanır, brauzer yaddaşına yazılmır və yeniləmədə silinmir. Model seçimi mövcuddur; ilkin model `gpt-4.1`.
- Açar saxlandıqdan sonra **Dərindən incələ və rapor yaz** aktiv olur. Seçilmiş seriyaların bütün dəstəklənən görüntüləri ardıcıl göndərilir, irəliləyiş göstərilir. Nəticə mövcud mətn qorunmaqla redaktora əlavə edilir. Görüntü seçilmədikdə əlavə tapşırıqdan mətn şablonu hazırlanır.
- Xəta və ya dayandırma zamanı hesabat dəyişmir. Dəstəklənməyən görüntülər səssizcə buraxılmır. API açarı yalnız həmin kompüterdən istifadə oluna bilər; paketdə və GitHub-da heç bir istifadəçi açarı yoxdur.
- AI nəticəsi radioloqun yoxlaması üçün layihədir; avtomatik diaqnoz kimi qəbul edilməməlidir. API sorğuları ayrıca ödənişlidir. Göndərmə yalnız istifadəçi hesabat düyməsini basdıqda başlayır; görüntünün özündə şəxsi məlumatlar varsa, onlar da göndərilə bilər.
- Lokal DICOM arxivi, PACS ayarları, lisenziya, hesabatlar və əvvəlki versiyaya təhlükəsiz geri dönüş qorunur.
- Mənbə kodu, Setup və sonrakı yenilənmələr əsas `drnaghiyev/RADAZ-D-COM` repozitoriyasına yönləndirildi.

**Yardım → Yeniləmələri yoxla → Yenilə → Proqramı yenidən aç**. Mövcud istifadəçilər üçün Setup-ı təkrar quraşdırmaq lazım deyil.
