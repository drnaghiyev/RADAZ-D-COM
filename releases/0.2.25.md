# RADAZ 0.2.25

- “Yenidən başlat” zamanı bəzi kompüterlərdə serverin dayanıb açılmaması düzəldildi. Veb-serverin başlatdığı yeniləyici əvvəlki serverlə birlikdə bağlanırdı; yeni versiyanı açacaq proses qalmırdı.
- Restart yalnız təsdiqlənmiş köhnə veb-serveri və onun render prosesini dayandırır. Yeniləyici, yeni versiyanın açılış prosesi və arxiv prosesi saxlanılır.
- Düzəliş köhnə versiyadan birbaşa 0.2.25-ə keçid zamanı da işləyir. JS/CSS yoxlaması, təhlükəsiz aktivləşdirmə və əvvəlki versiyaya geri dönüş qorunur.
- Lokal DICOM arxivi, PACS ayarları, lisenziya və istifadəçi məlumatları saxlanılır. Yenilənmə üçün Setup-ı yenidən quraşdırmaq lazım deyil.

**Yardım → Yeniləmələri yoxla → Yenilə → Proqramı yenidən aç**.
