# RADAZ 0.2.42

- Continuous left-button slice scrolling, wheel navigation and hover-based anatomical synchronization.
- Stable series drops into the selected viewport and protection against stale reconstruction results.
- Customizable one/two-row toolbars, named groups, reusable unplaced commands and visible confirmation.
- Coronal, Sagittal and Axial reconstruction inside the active viewer pane; independent per-series MPR/3D windows.
- Incremental folder, subfolder, ZIP, RAR and DICOM import without fixed total file/size limits, with persistent progress.
- Delta-only automatic updates. Full Windows Setup remains available for fresh installation.
- Previous runtime versions are removed after successful startup verification; archive, license and user settings remain separate.
