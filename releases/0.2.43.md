# RADAZ 0.2.43

- Alət qrupları üst və alt sıralarda yerləşdirilir; dar ekranlarda aşağıya keçərək görünən sahədə qalır.
- Hər qrup daxilində düymələri alt-alta yerləşdirmək üçün ayrıca seçim əlavə edildi.
- Qrupların sıralar arasında sürüklənməsi və düzülüşün yenidən açıldıqda saxlanması təkmilləşdirildi.
- Windows yenilənməsi yalnız dəyişmiş faylları daşıyan delta paketindən istifadə edir. İlk quraşdırma üçün tam Setup mövcuddur.

Yoxlama: 640, 1024, 1366 və 1920 piksel enlərində alət paneli, düzülüşün saxlanması, seriya sürükləmə, listələmə və MPR brauzer sınaqları.
