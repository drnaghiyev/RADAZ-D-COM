# RADAZ 0.2.49

- Smart Volume: manual contouring, Brush/Eraser, editable multiple segments,
  interpolation, voxel-based volume measurements and separate 3D surface view.
- MedSAM2: optional local research/education module, installed from Settings →
  Smart Volume; separate runtime and model download, explicit result review.
- Main 3D viewer and Smart Volume now share volume materials/presets, physical
  geometry and adaptive interaction quality. Includes latest bone color,
  lighting, volume preparation and viewport lifecycle changes.
- Includes latest toolbar, viewport typography, MRI native-series selection,
  localizer and coordinate fixes, plus updated assistant model selection.
- Preserves 0.2.48 packaging, cache, delta update and one-version rollback changes.

MedSAM2 is not clinically validated. Livewire and DICOM SEG are not implemented.
The model requires separate initial download and is research/education only.
No model weights, patient records, API credentials or local test data are in Setup.
