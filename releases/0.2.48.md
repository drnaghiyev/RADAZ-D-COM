# RADAZ 0.2.48

- Smaller Windows runtime payload: remove Electron demo content and unused Chromium languages while retaining AZ/RU/EN, codecs and PACS dependencies.
- Keep the active version and one stable rollback after successful activation; protect running and staged versions and unknown user files.
- Bound disposable HTTP cache to 256 MiB without clearing DICOM archives, IndexedDB, reports, settings or licenses.
- Standalone production packages no longer install an additional root node_modules tree.
- Preserve verified changed-file updates and add optional Windows installer signing. Builds without a configured certificate remain unsigned.

Smart Volume/MedSAM2 private prototypes and experimental 3D color changes are not included. Existing AI model folders and old private builds are not automatically removed.
