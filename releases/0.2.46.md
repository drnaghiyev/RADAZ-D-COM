# RADAZ 0.2.46

- Bölünmüş görüntü panellərində seriya sürükləmə və sürətli ardıcıl seçimlər sabitləşdirilib. Panel yenidən istifadə edilməzdən əvvəl əvvəlki yükləmə tamamlanır.
- Panel bağlandıqdan sonra qrafik buferin ölçüsü yenilənir; qara və yarımçıq görüntü problemi düzəldilib.
- Cobb bucağının Delete ilə silinməsi görüntünün vəziyyətini dəyişmir. Yarımçıq Cobb xətti üzərində hover xətası düzəldilib.
- Rentgen görüntülərinin zoom/pan vəziyyəti və ölçüləri hər panel üçün ayrıdır. WW/WL panel üzrə müstəqil qalır; KT/MRT sinxronlaşdırması saxlanılıb.
- Boş alət qrupları sağ klik menyusundan silinir və düzülüş yadda saxlanılır.

Yenilənmə yalnız dəyişmiş və çatışmayan faylları yoxlayıb yükləyir. Tam Windows Setup da mövcuddur. Lisenziya, DICOM arxivi və istifadəçi ayarları qorunur.
