# RADAZ 0.2.29

- RADAZ opens in a native desktop window with the existing design and viewer functions.
- One offline Setup includes the desktop shell, Node.js, Python and FFmpeg.
- Desktop and Start menu shortcuts start the local services automatically. Windows sign-in starts RADAZ; closing the main window keeps it in the tray.
- Existing GitHub update staging, rollback and the external clinical archive are retained.
- Experimental anatomy and brain segmentation modules are excluded from this public release.
