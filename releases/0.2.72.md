# RADAZ 0.2.72

- Add printed X-ray measurements to the captured print image. Disc packages include measured PNG copies in `MEASUREMENTS` while keeping the original DICOM pixels unchanged.
- Restore the web Smart Volume and 3D windows, and use Smart Volume's controls and volume presentation in the main Viewer 3D window.
- Add ultrasound cine controls with play, pause, stop and adjustable playback from 1 to 10 frames per second; improve local multi-frame ultrasound loading.

- Improve Viewer series cards and compact toolbar/side panel layout. Select a contrasting desktop icon for the Windows system theme.

MedSAM2 remains an optional research module. Its clinical accuracy and all image codecs require validation on the target examination and computer.
