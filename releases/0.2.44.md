# RADAZ 0.2.44

- İdxal üçün bir progressbar: ümumi faiz, cari mənbə və tam ədədlə emal edilmiş fayl sayı. Qovluq, ZIP və DICOM idxalı zamanı təkrar göstəricilər çıxarıldı.
- Local arxiv görüntüləri və pasiyent/seriya siyahısı mərhələli açılır. Hazır seriya digər seriyaların yüklənməsini gözləmədən MPR və 3D-də açıla bilir.
- PACS seriyaları arxivə yazıldıqca Viewer-ə əlavə olunur; sonrakı seriyalar istifadəçinin aktiv seçimini dəyişmir. CD/DVD hazırlığı da seriyalar üzrə izlənir.
- Təkrar idxal edilmiş eyni DICOM instansiyaları MPR/3D həcmində iki dəfə istifadə edilmir. Həqiqətən uyğunsuz koordinatlar və müxtəlif fazalar üçün qoruyucu yoxlamalar saxlanılır.
- 0.2.40, 0.2.41, 0.2.42 və 0.2.43-dən 0.2.44-ə birbaşa, bütün aralıq dəyişiklikləri ehtiva edən delta paketləri.
- Yeni yeniləyici imzalanmış son-versiya manifestinə əsasən hər faylı SHA-256 ilə yoxlayır. Növbəti yenilənmələrdə yalnız fərqli və ya çatışmayan faylların sıxılmış hissələri endirilir; dəyişməmiş runtime yerli nüsxədən götürülür.
- Yeni runtime ayrıca hazırlanıb bütövlüyü və açılışı yoxlanır. Lisenziya, arxiv və istifadəçi parametrləri versiya qovluqlarından kənarda saxlanılır; uğurlu aktivləşmədən sonra köhnə runtime təmizlənir.

Tam Windows Setup ilk quraşdırma və köhnə versiyanın yeniləyicisi zədələnmiş kompüterlər üçün də mövcuddur.
