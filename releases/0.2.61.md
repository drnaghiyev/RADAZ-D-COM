# RADAZ 0.2.61

- Movable toolbar customization group, persistent placement, and reliable empty-group removal.
- Direct folder and ZIP/RAR selection; explicit multiple-source import remains available.
- Touch pan, zoom and scrolling no longer also change WW/WL; long-press annotation deletion.
- Independent measurements and presentation synchronization, preserving different CT window presets.
- Responsive AI report editor, language selection, model/reasoning settings and report export improvements.
- RADAZ Voice opens the hosted Voice workspace separately from the AI assistant.
- Maximized auxiliary windows and hardened local startup/update handoff and diagnostics.
- Cumulative delta updates, full offline Windows Setup, preserved archive and license data.

Smart Volume and the optional MedSAM2 research module remain available. MedSAM2 is a research/education module and is not presented as clinically validated.
