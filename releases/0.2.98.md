# RADAZ 0.2.98

Windows-da RADAZ qısayolu əsas Viewer və lokal arxivi birbaşa başladır. Setup və proqramdaxili yeniləyici HTTPS bağlantısını Windows sertifikatları ilə yoxlayır. Sertifikatların bərpası lazım gəldikdə Windows administrator təsdiqi istəyir. İnternet kəsildikdə lokal arxivdən istifadə etmək mümkündür.

Android planşetində əsas Viewer-ə qayıtdıqdan sonra Lokal Arxiv düyməsi arxivi yenidən açır. Klinikadan göndərişlərdə bağlantı kəsilərsə, çatdırılma avtomatik təkrarlanır. Uyğun göndəriş xidmətinə qoşulmuş planşet yarımçıq faylı qaldığı yerdən qəbul edir.

Windows quraşdırıcısını və imzalı Android planşet APK-sını [RADAZ-ın yükləmə səhifəsindən](https://radaz.space/yukle) əldə edə bilərsiniz.
