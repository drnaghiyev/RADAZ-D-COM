# RADAZ 0.2.85

- Rentgen stitch ayrıca veb pəncərədə açılır. Kadrları ayrıca uyğunlaşdırmaq, kənarlardan kəsmək, parlaqlıq və kontrastı dəyişmək mümkündür.
- Əsas Viewer-in ölçü alətləri birbaşa stitch görüntüsündə işləyir. Pan, zoom və kadr yerdəyişməsində ölçülər görüntü ilə birlikdə saxlanılır.
- Ölçülərlə birləşdirilmiş rentgen ayrıca DICOM faylı kimi saxlanır. Mənbə fayllar dəyişmir; əlavə pasiyent və proqram yazıları görüntünün üzərinə çəkilmir.
- Alətə ikinci klik onu deaktiv edir. Mərkəzləşdirmə kadrların nisbi uyğunluğunu saxlayır.
- Əsas paneldə sağda gizlənən alət qruplarının əlavə menyusu düzəldilib.
- DICOM Lite görüntünü mərkəzləşdirir; uzunluq, sıxlıq, bucaq və Cobb ölçülərinin redaktəsi və silinməsi təkmilləşdirilib.
- Ölçülü rentgen nüsxələri CD paketinə ayrıca DICOM kimi daxil edilir; orijinallar qorunur.

MedSAM2 ayrıca tədqiqat moduludur. Windows Setup və mövcud versiyalardan fərqli fayllarla yenilənmə təqdim olunur.
