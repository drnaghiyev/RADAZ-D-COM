# RADAZ 0.2.90

- Windows Desktop-da **Local Arxiv** düyməsinin yanındakı oxla **DICOM Network** bölməsini açmaq olur.
- Lokal arxivdə və PACS-da işarələnmiş müayinələri radioloqa, növbətçiyə və ya ikinci rəy üçün göndərmək mümkündür. Hər klinika öz istifadəçilərini, cihazlarını və növbələrini idarə edir.
- Orijinal DICOM faylları şifrəli ötürülür. Qəbul təsdiqləndikdə faylların bütövlüyü yoxlanılır və onlar lokal arxivə daxil edilir. Bağlantı kəsildikdə növbə saxlanır.

Klinika ilə başqa şəbəkədəki noutbuk arasında sınaq üçün hər iki kompüteri eyni HTTPS koordinatoruna öz cihaz dəvəti ilə qoşun. Bağlantını əvvəlcə sintetik müayinə göndərərək yoxlayın. Quraşdırma addımları [administrator bələdçisində](https://github.com/drnaghiyev/RADAZ-D-COM/blob/v0.2.90/ops/private-network.md) verilib.
