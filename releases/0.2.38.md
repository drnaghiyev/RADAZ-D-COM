# RADAZ 0.2.38

- Local Arxiv və PACS pəncərələrində seçilmiş müayinələri RADAZBRIDGE-ə göndərmək üçün düymə əlavə edildi.
- RADAZBRIDGE IP, port, Called AE və Calling AE ayarları bu kompüterdə saxlanılır; DICOM bağlantısını ayrıca yoxlamaq mümkündür.
- Disk arxivindən və DIMSE PACS-dən müayinə faylları ardıcıl C-STORE ilə ötürülür. DICOMweb mənbələrində tam müayinə siyahısı səhifələrlə oxunur və orijinal DICOM-lar göndərilir.
- Qəbul edilmiş faylların sayı, xəbərdarlıqlar, yarımçıq göndəriş və dayandırma göstərilir. Arxivdəki orijinallar saxlanılır; göndəriş zamanı Desktop yenilənməsi arxiv xidmətini dayandırmır.

RADAZBRIDGE-də Viewer kompüterinin lokal IP-si və Calling AE adı icazəli olmalıdır. Standart qəbul AE adı RADAZBRIDGE, port 11112-dir; başqa kompüterdəki Bridge üçün onun lokal IP-sini daxil edin. Bridge-in DICOM qəbul təsdiqi bulud sinxronizasiyasının bitməsi demək deyil; onu Bridge panelində izləyin.
