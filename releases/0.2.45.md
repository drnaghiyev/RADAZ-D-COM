# RADAZ 0.2.45

- İdxalda vahid progressbar, ümumi faiz, cari mənbə və tam ədədlə fayl sayı. Local arxiv, PACS, CD/DVD, qovluq və ZIP yüklənərkən pasiyent/seriya siyahısı mərhələli yenilənir.
- Hazır seriya digər seriyaları gözləmədən MPR və 3D-də açıla bilir. Eyni DICOM instansiyasının təkrar idxalı MPR koordinatlarını pozmur.
- 0.2.40–0.2.44 versiyalarından birbaşa son versiyaya bütün aralıq dəyişiklikləri daxil edən delta paketləri.
- Fayl bərpasında GitHub yönləndirməsi təkrar istifadə olunur; müvəqqəti şəbəkə məhdudiyyətlərində gözləyib yenidən cəhd edilir. Hər faylın SHA-256 yoxlaması saxlanılır, yalnız dəyişmiş və çatışmayan fayllar yüklənir.
- 0.2.44-dən keçid uyğun delta paketi ilə aparılır. Yeni fayl transportu sonrakı yenilənmələrdə də zədələnmiş və çatışmayan faylları yoxlayıb bərpa edir.
- Yeni versiya açılış yoxlamasından keçdikdən sonra köhnə runtime təmizlənir; lisenziya, DICOM arxivi və istifadəçi ayarları qorunur.

Tam Windows Setup ilk quraşdırma və köhnə yeniləyicisi zədələnmiş kompüterlərin bərpası üçün də mövcuddur.
