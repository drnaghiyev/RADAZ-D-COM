# RADAZ 0.2.87

- Local Arxiv və PACS-da CD/DVD hazırlığı checkbox ilə seçilmiş müayinələri götürür; aktiv sətir seçimə əlavə edilmir.
- Checkbox seçimi olmadıqda CD/DVD düyməsi deaktivdir. Bir neçə seçilmiş müayinə üçün ayrıca hazırlama pəncərələri açılır.
- Əvvəl lokal yoxlanmış CD hazırlığı və DICOM Lite yenilikləri daxil edilib: mərhələli irəliləyiş, təkrar oxumanın azaldılması, əsas Viewer-in ölçü, HU, parlaqlıq, pan və zoom alətləri.

Windows quraşdırılması, əvvəlki versiyalardan yenilənmə və geri qaytarma sınaqları tətbiq olunur. Fiziki CD/DVD yazılması uyğun yazıcı və boş disk tələb edir.
