# RADAZ 0.2.31

- Grouped, responsive icon toolbars with larger controls on wide displays; MPR and 3D text icons.
- Updated RADAZ vector logo and AZ/RU/EN taglines.
- 3D orientation cube preserves the volume centre when a face is selected, with face-aligned letters.
- Non-destructive 3D scalpel, undo/reset and rotate controls. Cuts affect the displayed volume only.
- Adjustable WW/WL for the AI assistant preview and the images submitted for analysis.
- Anatomy atlas, local CT/MR segmentation interfaces, mask editing and surface export. Segmentation requires a separately installed model runtime; this Setup does not download model weights.
- Separate 30-day segmentation trial and module entitlement support. Default catalogue price is 5 AZN/month; an existing signed administrator pricing policy takes precedence. Live payment activation remains dependent on the configured seller service.

The admin vault password and Windows file permissions are unchanged by this update. Image detail remains limited by the source DICOM resolution and acquisition protocol. Segmentation results require review.
