# RADAZ 0.2.92

- DICOM Network-də klinika administratoru radioloqun və ya əməkdaşın sətrindən onun adını, rolunu, icazələrini və aktivliyini dəyişə bilər.
- Əməkdaşı siyahıdan silərkən proqram adı göstərir və təsdiq istəyir. Silmə həmin klinikaya girişə və yeni göndərişlərdə alıcı seçiminə təsir edir. Əvvəlki müayinələr və göndəriş tarixçəsi saxlanılır.
- Yeni əməkdaş üçün ayrıca forma açılır. Mövcud hesab ID-si təkrar daxil ediləndə proqram bu barədə məlumat verir.
- DICOM Network ayarlarını açmaq və dəyişmək üçün lokal şifrə tələb olunur. İlk açılışda hər Windows istifadəçisi həmin quraşdırmaya öz şifrəsini təyin edir. Ayarlar kilidli olanda müayinələrin göndərilməsi və qəbulu davam edir.

Bu əməliyyatlar üçün **Yardım → Ayarlar → DICOM Network ayarları → Klinikalar və radioloqlar** bölməsini açın. Ayrıca HTTPS serverində DICOM Network işlədən klinikalar həmin serverdəki koordinatoru da 0.2.92-yə yeniləməlidir.
