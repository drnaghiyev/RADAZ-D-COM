# RADAZ 0.2.93

DICOM Network ayarlarında **Bağlantı → RADAZ İnternet · klinika və həkimlər** seçin. Həkimin kompüterində **Qoşul və kompüter ID-si al** düyməsi paylaşmaq üçün ID verir. Klinikada eyni bölmədən göndərən kompüter üçün klinika yaradın. Hər həkimin adını və kompüter ID-sini daxil edib dəvət göndərin. Dəvət həkimin RADAZ pəncərəsinə gəlir və 24 saat ərzində qəbul edilə bilər.

Həkim dəvəti qəbul etdikdən sonra klinika Local Arxivdə və ya PACS siyahısında müayinəni işarələyib **RADAZ-a göndər** düyməsindən bir və ya bir neçə həkimi seçə bilər. İnternet bağlantısı və əvvəlki şəxsi şəbəkə ayrı işləyir.

Əsas Viewer-ə sürüşdürülən fayl və ZIP-lər baxış üçün açılır. Çoxkadrli MRT-də kontrast, piksel ölçüsü və lokalayzer koordinatları müvafiq kadrdan oxunur. Sıxılmadan saxlanan ZIP-lər və çoxkadrli görüntülər mərhələli açılır. Əsas Viewer-in demosu kompüterdə ilk istifadə tarixindən altı təqvim ayı davam edir.
