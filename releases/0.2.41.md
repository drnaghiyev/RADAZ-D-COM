# RADAZ 0.2.41

- Alət panelində fərdi düymələri və menyu əmrlərini qruplar arasında daşımaq, yeni qrup yaratmaq, adlandırmaq, silmək və standart düzülüşü bərpa etmək. Düzülüş kompüterdə saxlanılır.
- CD, Local arxiv və PACS müayinələri eyni Viewer sessiyasında qalır. Pasiyentin × düyməsi yalnız onun açıq görüntülərini bağlayır.
- Uyğun KT/MRT seriyaları üçün fiziki DICOM koordinatları əsasında Sync Scroll. Rentgen görüntülərinin ayrıca zoom/pan yaddaşı.
- MPR müstəvilərini əsas Viewer-də Axial–Coronal–Sagittal düzülüşündə açmaq; təkrar pəncərə açılışında mövcud pəncərəni önə gətirmək. Arxiv, PACS və 3D üçün əsas/ayrı pəncərə seçimi.
- 1920×1080-də alətlərin bir sətirdə görünməsi və versiyanın proqram başlığında göstərilməsi.
- SHA-256 əsasında delta paylanması, dəyişmiş/yeni/silinmiş fayl manifesti, Ed25519 ilə imzalı yeniləmə məlumatı, yarımçıq yükləmənin davamı və tam paketə ehtiyat keçid.
- Aktiv, əvvəlki və işləyən versiyaları qoruyan köhnə runtime təmizlənməsi. Arxiv, lisenziya və istifadəçi məlumatları versiya qovluqlarından kənarda saxlanılır.

Tam quraşdırma: `RADAZ-Setup-v0.2.41.exe`. Yeniləmə paketinin ölçüsü başlanğıc versiyadan asılıdır; uyğun delta yoxdursa və ya yerli runtime faylları dəyişibsə, tam paket istifadə olunur.
