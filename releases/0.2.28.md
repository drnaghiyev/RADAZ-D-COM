# RADAZ 0.2.28

- İlk Setup quraşdırması lokal xidmətləri avtomatik arxa planda başladır. RADAZ ikonlu iş masası, Start menyusu və Windows açılışı qısayolları proqramın quraşdırıldığı yeri istifadə edir.
- Qısayol localhost hazır olduqdan sonra RADAZ pəncərəsini açır; pəncərə bağlandıqda lokal xidmətlər işləməyə davam edir. Mövcud quraşdırmada yeniləmə növbəti açılışa saxlanılır.
- Deviation üçbucağının daxili sahəsindən tutub bütöv ölçünü daşımaq mümkündür. Hündürlük və bucaq dəyişmir, uclar ayrıca düzəldilə bilir.
- Aylıq ödəniş bölməsi və lisenziya pəncərəsindəki ödəniş forması çıxarılıb.
- Proqram haqqında bölmədə müəllif və proqramın funksiyaları göstərilir; xarici buraxılış keçidi çıxarılıb.
