# RADAZ 0.2.47

- Viewer, MPR və 3D pəncərələrinin GPU kontekst istifadəsi azaldılıb. Rekonstruksiyadan sonra panel bölünməsi və seriya sürükləməsində qara ekran problemi düzəldilib.
- Seriyaların yüklənmə vəziyyəti ayrıca hesablanır. MPR və 3D mövcud seriyanın kəsiklərini hazırlayır, digər seriyaların idxalının bitməsini gözləmir.
- Artan 3D seriyalarında əvvəlki render sorğuları yeni görünüşün resurslarına müdaxilə etmir.
- Sync aktiv olduqda panellər arasında zoom, pan və WW/WL sinxronlaşdırılır. Uyğun KT/MRT kəsiklərinin anatomik sinxron listələnməsi saxlanılır. Fırlatma və ölçülər ötürülmür.
- Yeni ölçü və işarələr yalnız çəkildiyi paneldə göstərilir.

Yalnız dəyişmiş və çatışmayan fayllar yenilənir. Tam Windows Setup da mövcuddur. Lisenziya, arxiv və istifadəçi ayarları qorunur.
