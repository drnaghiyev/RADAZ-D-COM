# RADAZ 0.2.22

- WW/WL yalnız aktiv görüntüdə dəyişir. Digər kəsit və panellərin ayarları dəyişmir; görüntüyə qayıdanda onun öz ayarı bərpa olunur.
- CD/DVD importu Local arxivə yazır, hazır görüntüləri arxivdən Viewer-ə ötürür. Başqa müayinə açmaq importu dayandırmır və arxa plandakı import aktiv müayinəni dəyişmir.
- Local arxiv və PACS mövcud Viewer-i önə gətirir və maksimum ölçüdə açır; arxiv/PACS pəncərələri kiçildilmir.
- Yenilənmə pəncərəsində Setup endirmə keçidi yoxdur. “Yenilə” bir kliklə avtomatik endirir və hazırlayır; “Proqramı yenidən aç” yenilənməni tətbiq edib proqramı yenidən başladır. Hazır olduqda pəncərə öz-özünə bağlanmır.
- Lokal arxiv yenilənmə və yenidən başlatma zamanı qorunur.
