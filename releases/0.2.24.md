# RADAZ 0.2.24

- Uğursuz açılışdan sonra yenilənmənin daimi bloklanması düzəldildi. “Yenilə” ilə yenidən endirmə və yoxlama mümkündür; ayrıca Setup açmaq lazım deyil.
- GitHub paketi və hər fayl SHA-256 ilə yoxlanılır. Yeni açılışda JS, CSS, şriftlər, DICOM kodekləri və digər brauzer resursları həm diskdə, həm HTTP ilə yoxlanılır; əsas səhifələrin açılması təsdiqlənir.
- Yeni versiya yalnız yoxlamadan sonra aktiv edilir. “Proqramı yenidən aç” düyməsi və digər RADAZ pəncərələri bu təsdiqi gözləyir.
- Köhnə Service Worker nəzarəti aradan qaldırılır; HTML və resurslar keşdən qarışdırılmır, açılış konkret build ilə əlaqələndirilir.
- Xətanın mərhələsi, səbəbi və uğursuz geri qaytarma ayrıca Developer Console və `logs/update-errors.jsonl` jurnalında görünür. Arxiv açılış jurnalları əvvəlki cəhdlərin üzərinə yazılmır.
- Uğursuz yenilənmə əvvəlki versiyanın fayllarını saxlayır. Lokal DICOM arxivi, PACS ayarları, lisenziya və brauzer istifadəçi məlumatları silinmir.

Yenilənmə: **Yardım → Yeniləmələri yoxla → Yenilə → Proqramı yenidən aç**. Setup.exe ayrıca ilk quraşdırma üçündür.
