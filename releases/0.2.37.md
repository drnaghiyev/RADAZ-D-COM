# RADAZ 0.2.37

- Saytın admin panelində yaradılan RZ- lisenziya açarları proqramda aktivləşdirilir.
- Açar kompüter koduna və sabit quraşdırma identifikatoruna bağlanır; cihaz limiti serverdə yoxlanılır.
- Aktivasiya və dövri yoxlama HTTPS ilə license.radaz.space üzərindən aparılır. Rəqəmsal imza proqramla verilən sabit açarla yoxlanılır.
- Windows-da saxlanmış aktivasiya açarı istifadəçiyə bağlı DPAPI şifrələməsi ilə qorunur.
- Mövcud RADAZ1 və RADAZ-ACT lisenziyaları saxlanılır. Lokal arxiv və müayinə faylları dəyişdirilmir.

İlk aktivasiya və dövri yoxlama üçün internet lazımdır. Serverin verdiyi yoxlama icazəsi ən çox 15 dəqiqə etibarlıdır; bağlantı bu müddətdən uzun kəsilərsə, yeni lisenziyanın təsdiqi internet bərpa olunana qədər mümkün deyil.
