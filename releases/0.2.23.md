# RADAZ 0.2.23

- KT (CT) və MRT (MR) üçün WW/WL seçilmiş seriyanın bütün kəsitlərinə tətbiq olunur. Eyni seriyanın digər panelləri də yenilənir; başqa seriyaların ayarları dəyişmir.
- MPR-in aksial, koronal və sagital görünüşləri eyni WW/WL ayarını paylaşır. Kəsit dəyişəndə, MIP və qalınlıq dəyişikliklərindən sonra ayar saxlanılır; ayrıca MPR pəncərəsi ilə Viewer sinxron qalır.
- Rentgen (CR/DX və digər proyeksiya görüntüləri) üçün yalnız aktiv görüntünün WW/WL-si dəyişir. Başqa görüntü və panellərin ayarları qorunur.
- Yenilənmə proqram daxilində “Yenilə” ilə hazırlanır, “Proqramı yenidən aç” ilə tətbiq olunur; ayrıca Setup açmaq tələb edilmir. Lokal arxiv saxlanılır.
