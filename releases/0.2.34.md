# RADAZ 0.2.34

- Scale command buttons with screen width: 32–64 px, including 48 px at 1920 px. Preserve spacing and a single header row; move only groups that do not fit into the additional-tools menu.
- Drag toolbar groups by their grip to reorder them or dock them on the right. Viewer, MPR, 3D, Local Archive and PACS remember separate arrangements. Empty right docks disappear. Remove nested Local Archive group frames.
- Enable folder export from trusted RADAZ Desktop windows. Browser exports also start the file download when ready.
- Keep patient and corner text fixed while zooming the image in print preview, PDF and DICOM print. Add 5×5 and 6×6 layouts to Viewer and printing.
- Show the recorded clinic name and add searchable DICOM metadata for the active image. Use recorded protocol, sequence and acquisition information when the series description is missing.
- Load CD/DVD and compressed-series thumbnails without requiring a click on each series.
- Browse the active series with the Up/Down arrow keys. Cancel unfinished measurements when replacing or closing their viewport, and avoid resetting a stack for thumbnail-only updates.

Existing archive data is preserved. Updates are staged for the next launch; an active examination is not interrupted.
