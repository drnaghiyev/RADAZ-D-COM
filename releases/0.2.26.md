# RADAZ 0.2.26

- Viewer-də ayrıca **Sıfırla** düyməsi: parlaqlıq, kontrast, pozitiv/neqativ, zoom, mövqe, fırlatma və əks çevirmə ilkin vəziyyətə qaytarılır. Qısayol: Ctrl+Shift+\. Cari kəsit və ölçmələr saxlanılır. KT/MRT pəncərələməsi seriya və MPR üzrə, rentgendə isə aktiv görüntü üzrə qalır.
- Sola/sağa 90°, 180°, üfüqi və şaquli çevirmə düymələri birbaşa yan-yana yerləşdirildi. 3D sıfırlama işıq, preset və şəffaflığı da bərpa edir.
- Quraşdırılmış RADAZ Windows-a girişdə avtomatik başlayır. RADAZ qısayolu adi brauzer vərəqəsi əvəzinə Edge/Chrome tətbiq pəncərəsini açır. Mövcud Chromium profilindən və eyni localhost ünvanından istifadə olunur.
- Hazır yeniləmənin tətbiqi GitHub sorğusunu və endirmə prosesinin kilidini gözləmir. Server dayandıqda fon nəzarətçisi aktiv versiyanı yenidən başladır; hazır, hələ tətbiq edilməmiş yeniləməni özbaşına aktivləşdirmir.
- **Hesabat** bölməsi **AI asistent** adlandırıldı. Aktiv müayinənin bütün seriyaları və görüntüləri daxil edilir; başqa müayinə ilə qarışdırılmır. Lokal önbaxış, əlavə tapşırıq sahəsi və saxlanılan hesabat redaktoru mövcuddur.
- İstifadəçinin seçiminə əsasən AI bağlantısı qoşulmayıb. Avtomatik görüntü analizi və mətn yaratma aktiv deyil; ChatGPT pəncərəsi açılmır və görüntülər AI xidmətinə göndərilmir.
- Lokal DICOM arxivi, PACS ayarları, lisenziya, mövcud hesabatlar və təhlükəsiz geri dönüş saxlanılır. Yenilənmə üçün Setup təkrar quraşdırılmır.

**Yardım → Yeniləmələri yoxla → Yenilə → Proqramı yenidən aç**.
