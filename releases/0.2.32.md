# RADAZ 0.2.32

- Single-row grouped toolbar. On narrow windows, additional tools open in a menu instead of making a second toolbar row or shrinking all controls. Rotation/flip controls have their own group without nested group frames.
- Retain TotalSegmentator CT/MR segmentation; remove the separate anatomy atlas and experimental radiograph-recognition module and bundled atlas images.
- Bone VR uses an ivory cortical-bone palette, warm low-density transition, neutral lighting and less specular glare. Stationary rendering preserves the chosen quality on lower-end GPUs; interaction can use a faster preview.
- Add verified file-level differential updates. Reusable files are copied to a new version directory and checked against the target manifest. The running installation and clinical archive remain untouched. Modified or missing base files trigger a verified full-package fallback.

## Update compatibility
Existing 0.2.31 and older updaters need one complete update to install this capability. From 0.2.32 onward, matching differential packages can download only changed files. Setup remains a complete offline installer; skipping versions without a matching differential package may require a full update.

Rendering cannot recover anatomy absent from the source data. Fine detail requires suitable thin-section source images; separate lung/airway/vessel colours require corresponding segmentation masks.
